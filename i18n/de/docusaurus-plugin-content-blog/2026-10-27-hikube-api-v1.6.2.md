Diese Version verbessert die interne Nachverfolgung der API-Anfragen. So können wir einen Vorfall oder eine Support-Anfrage schneller analysieren. Das Verhalten der API ändert sich nicht, und Sie müssen nichts unternehmen.

<!-- truncate -->

## Geändert

- **API** — Genauere interne Nachverfolgung der Anfragen. Antworten, Fehler und die [API-Referenz](/api/reference/hikube-api) bleiben unverändert.
