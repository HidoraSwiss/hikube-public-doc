# Introduction to Hikube

## What is Hikube?

**Hikube** is a sovereign enterprise cloud platform hosted in Switzerland. You deploy virtual machines, Kubernetes clusters, databases and storage from a single web console: [console.hikube.cloud](https://console.hikube.cloud).

### Infrastructure and availability

**Sovereign cloud, data hosted in Switzerland**
- All your data stays on Swiss territory, in line with local data protection regulations.

**High availability across three datacenters**
- Replicated storage is spread across three geographically separate datacenters in Switzerland.

**Green IT datacenter**
- Datacenter powered by renewable energy.

### Services

**Managed Kubernetes**
- Create Kubernetes clusters in a few clicks, with node groups, autoscaling and preconfigured add-ons.

**Linux and Windows virtual machines**
- Deploy VMs from ready-to-use images, with persistent disks and a public IP if needed.

**GPU**
- Add NVIDIA GPUs to your VMs or Kubernetes node groups for AI, machine learning or high-performance computing.

**Managed databases and messaging**
- PostgreSQL, MariaDB, MongoDB, Redis and RabbitMQ, with users, databases and access managed from the console.

**Storage**
- Persistent disks for your VMs and S3-compatible buckets.

### Security and isolation

- Each **project** is isolated from the others: its own network, resources and quotas.
- Stored data can be encrypted.
